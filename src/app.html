MT5 verbinden

Einmalig, am Computer mit MT5 (Mac oder Windows). Dauert etwa 10 Minuten. Deine Daten landen in deinem eigenen, geheimen GitHub-Gist und nur dein Handy liest sie.

  1. GitHub-Konto erstellen, falls du keins hast: github.com/signup
  2. Token erstellen: diesen Link öffnen, bei Ablauf „No expiration“ wählen, ganz unten „Generate token“. Den Code ghp_… kopieren und niemandem schicken.
  3. Expert Advisor holen: am Computer diesen Code öffnen, alles markieren und kopieren.
  4. In MT5 IDE (F4) öffnen → Datei → Neu → Expert Advisor (Vorlage) → Name BullionMonkeySync → Fertig. Alles darin ersetzen durch den kopierten Code, dann Kompilieren (0 errors).
  5. In MT5 Extras → Optionen → Expert Advisors: „Algorithmischen Handel erlauben“ und „WebRequest erlauben“ anhaken, darunter https://api.github.com, https://www.financialjuice.com und https://trumpstruth.org hinzufügen.
  6. Im Navigator unter Experten „BullionMonkeySync“ auf einen Chart ziehen, bei Eingaben im Feld GitHubToken deinen Token einfügen, OK.
  7. Es erscheint die Meldung „Verbunden. Gist-ID für die App“. Auf dem Handy gist.github.com öffnen, „Bullion Monkey MT5“ antippen, den Link kopieren und hier im Dashboard bei MT5-Verbindung einfügen.
  8. Optional für Push-Nachrichten: MetaQuotes ID aus der MT5-App am Handy (Einstellungen → Nachrichten) in MT5 am Computer unter Extras → Optionen → Benachrichtigungen eintragen.

MT5 muss am Computer laufen, damit Trades, Positionen und Schlagzeilen aktuell bleiben. News-Kalender, Checkliste und Lot-Rechner gehen auch ohne.
